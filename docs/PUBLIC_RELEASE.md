# 公开版本说明

整理日期：2026-11-05。

公开版保留桥接、人格与记忆模块、MCP 接口、管理界面、合成测试和已有组件许可。内部计划、审查、返工交接、迁移文件、测试执行日志以及未经确认可公开的个人形象素材不在公开范围。

源码中的原始管理员、机器人、群与直播目标标识已改为合成示例，关联昵称与个性化直播提示已泛化。本机用户目录和运行时位置已改为示例或环境变量；模型中转服务采用不可解析的示例域名，需要自行配置。

公开版使用独立 Git 历史；原始内部提交保留在私有备份库。请勿把私有开发分支直接推送或合并到本库。

公开整理没有进行生产部署，也没有向真实 QQ、B 站或小红书账号发送测试内容。公开检查的结果不等同于完整系统验收；既有功能、权限、可移植性或模型表现仍可能存在缺陷。

公开文件检查：

```powershell
node tools/check-public-release.mjs
```

该检查检测凭据格式、私人路径、身份标识和不应入库的数据目录。它是辅助检查，不能证明文本完全不含隐私；新增自然语言材料仍需人工审阅。
